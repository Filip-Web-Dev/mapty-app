 Mapty - Map Your Workouts

Mapty is a web application that allows users to track and log their running and cycling workouts on an interactive map using geolocation and the Leaflet library.

Key Features
- Geolocation API: Automatically detects user location and centers the map.
- Interactive Map: Add workout markers by clicking directly anywhere on the map.
- Workout Tracking: Log running (cadence, pace) and cycling (elevation gain, speed) activities.
- Dynamic Form: Form inputs toggle dynamically based on the selected activity type.
- Local Storage Persistence: Workouts are saved in local storage and reloaded upon page refresh.
- Navigation: Click on a saved workout in the sidebar list to center the map on its location.

Tech Stack
- HTML5 and CSS3: Layout built with Flexbox and custom CSS styling.
- JavaScript (ES6+): Object-Oriented Programming (OOP) using classes, inheritance, private properties, and DOM event handling.
- Leaflet.js: Third-party library used for displaying maps and custom location markers.
- Web APIs: Geolocation API and LocalStorage API.

Project Context
Developed as part of practical training to practice Object-Oriented Programming (OOP) architecture, third-party library integration, asynchronous geolocation handling, and LocalStorage data handling in JavaScript.
